# くさむらモンスター モンスター一覧と詳細

`tools/make_dex.py` が ゲームの データから じどうで つくる ファイル（てで かきかえない）。`python3 tools/build.py` の たびに さいしんに なる。

ぜんぶで **87ひき**（ずかん `DEX` の じゅん）。

## きづいた こと

- タイプ べつ（ダブルタイプは りょうほうで かぞえる）：いわ 13・みず 12・ひこう 11・ドラゴン 11・ほのお 10・くさ 10・ノーマル 8・エスパー 8・でんき 7
- ダブルタイプ：ウッピー・ミネゾーウ・さざなみ
- やせいに でない（トレーナーの てもち だけ）：カガリビ・ザンテツリュウ・オオツノリュウ・ライハリオン・ユラメキ・オオコダマ
- おぼえる わざが 3つ いか：ピヨット・ヒダネ・コロマグ・ハネトカゲ・ツノリュウ
- しんか しない（でんせつ・まぼろし いがい）：ヤドイワ・ウミドリー・プラグル・フワクラ・ナミガメ・トビウオン・カザンドリ・ミズチノガミ・ゴロネコ・ハクタク・フクロウジイ・カザミドリ
- ルール（しんかLv・わざLv・でんせつの じゅんばん など）は AGENTS.md の「モンスター」を みてね
